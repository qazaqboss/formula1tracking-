# F1 Pulse — трекинг Формулы 1

Статический сайт (HTML + ES-модули + three.js, без сборки) с 3D-визуализацией и данными Формулы 1 в киберпанк-стиле: неон, bloom-свечение, сканлайны, фон из движущихся точек. Вёрстка адаптирована под телефон.

## Разделы

- **3D-болид** — детализированная PBR-модель (`models/car.glb`, ~3 МБ) в ливреях всех 11 команд сетки 2026 (`models/liveries/<команда>.jpg` + `-mr.jpg` металл/шероховатость, подгружаются только при выборе): McLaren №1, Ferrari №16, Red Bull №3, Mercedes №12, Aston Martin №14, Alpine №10, Williams №23, Racing Bulls №30, Haas №87, Audi №5, Cadillac №77. Только цвета команд — без логотипов спонсоров и эмблем. Узлы (монокок, Halo, антикрылья, колёса со стойками) раздвигаются кнопкой «Разобрать болид», рентген показывает каркас, колёса крутятся на своих осях. Сцена — аэродинамическая труба с потоками частиц и неоновым полом. Ниже — отсчёт до следующего Гран-при, лидеры чемпионата, итог последней гонки.
- **Дашборд** (стартовая страница) — полоса уикенда (FP1…Гонка со статусом), KPI-плитки (лидер, лучший круг, прогресс, флаг, асфальт) и дашборд сессии на данных [OpenF1](https://openf1.org):
  - 3D-трасса по телеметрии; болиды едут по ней со светящимися хвостами (позиция считается по времени кругов);
  - шкала перемотки и бегущая строка сообщений дирекции гонки;
  - анимированная перестановка позиций, ▲▼ отыгранные места, подсветка DRS (интервал < 1 с);
  - тайминг: позиция, интервал, отставание от лидера, последний круг (фиолетовый — лучший в сессии, зелёный — личный), шины и их возраст;
  - график времени кругов (выбранный пилот против лидера);
  - **оценка пилотов** 1–10 (позиция, отыгранные места, темп относительно лучшего круга, стабильность);
  - сообщения дирекции гонки, погода, последние новости, ссылки на гонку (F1 Live Timing, хайлайты, F1 TV, Википедия);
  - **во время сессии — реальное время**: OpenF1 на время сессии закрывает API, поэтому функция Vercel `api/live.mjs` читает официальный поток F1 Live Timing (SignalR — тот же, что пишет ingestor [OpenF1](https://github.com/br-g/openf1)) и отдаёт компактный снимок; дашборд обновляется каждые 5 с (позиции, интервалы, круги, шины, дирекция гонки, погода, статус трассы), контур трассы — из открытого API MultiViewer; после — **повтор** самой свежей сессии (включая квалификацию) запускается сам (1–60×);
  - если OpenF1 недоступен — включается демо-гонка, чтобы дашборд никогда не стоял пустым.
- **Пилоты** — карточки с фото, очками, победами; по клику — результаты сезона и статистика карьеры.
- **Конструкторы** — Кубок конструкторов.
- **Гонки** — календарь и результаты любого сезона с 1950 года, ссылки на видео и Википедию.
- **История** — легендарные гонки (1976–2024): полные результаты, видео, статьи.
- **Новости** — свежие материалы Motorsport.com, Autosport, RaceFans, The Race (RSS).

## Превью ссылки

`og.png` (1200×630) — картинка для Telegram / WhatsApp / X / Discord, подключена мета-тегами Open Graph и Twitter в `index.html`.

## Запуск

Нужен любой статический сервер (ES-модули не работают через `file://`):

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
# живой режим (/api/live) работает на Vercel или через `vercel dev`
```

Подходит для GitHub Pages / Vercel / Netlify без настройки.

## Источники данных

| Что | Откуда |
| --- | --- |
| Сессии, круги, позиции, интервалы, шины, телеметрия, погода, дирекция гонки | OpenF1 `api.openf1.org` |
| Реальное время во время сессии | F1 Live Timing через `api/live.mjs` |
| Контур трассы в живом режиме | MultiViewer `api.multiviewer.app` |
| Таблицы чемпионата, календарь, результаты, история | Jolpica (Ergast) `api.jolpi.ca` |
| Новости | RSS через `api.rss2json.com` |

> Запросы к OpenF1 идут через очередь (бесплатный тариф ограничивает частоту, на 429 — повтор с паузой).
>
> OpenF1 отдаёт исторические данные бесплатно, но во время сессии закрывает API без ключа — тогда работает собственный ретранслятор `/api/live` (кэш на edge 4 с, все зрители делят один запрос к F1). Положение машин на трассе в живом режиме оценивается по секторам и отставанию (координаты машин F1 без авторизации не отдаёт).

Видео открываются поиском на YouTube / F1 TV — сайт не встраивает и не хранит чужой контент.

Неофициальный фан-проект, не связан с Formula 1 / FOM. three.js — MIT (`js/vendor/THREE_LICENSE`).
